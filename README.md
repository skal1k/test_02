# test_02
Второй тест карты для Garry`s Mod, теперь в файле .BSP, а не в отдельном сохранении.

Карта представляет собой небольшую бетонную постройку с уличными объектами (скамейки, мусорная урна и столб с часами).

Карта также опубликована в мастерской самой игры: https://steamcommunity.com/sharedfiles/filedetails/?id=3814540028

Построено в Valve Hammer Editor - официальном инструменте от разработчиков.
